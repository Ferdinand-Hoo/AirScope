# Bound the first-release wireless controls

The first release will configure SSID visibility, Security Profiles, channels
1 through 13, CSA count, 802.11 b/bg/bgn/gn protocol modes, HT20/HT40
bandwidth, maximum transmit power, client limit, beacon interval, and DTIM
period through validated Security and Radio Profiles. Espressif LR, FTM, CSI,
sniffing, Vendor IE, WPS, DPP, and Enterprise authentication are separate
experiment domains and are excluded from this release.
